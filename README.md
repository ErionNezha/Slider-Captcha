# 🧩 Slider Captcha

Captcha interaktive me rrëshqitje (puzzle): përdoruesi tërheq shigjetën djathtas dhe vendos pjesën e prerë të figurës në vendin e saktë. Verifikimi bëhet lokalisht (pozicion + gjurmë lëvizjeje). Figurat gjenerohen lokalisht — pa shërbime të jashtme.

## Si ta hapësh

Hap `index.html` në browser — tab-i **Live Demo** tregon demon funksionale, tab-i **Kodi Burim** tregon të gjithë kodin.

Ose hap direkt `demo/index.html` për demon.

## Struktura

- `index.html` — faqe showcase (Live Demo + Kodi Burim)
- `demo/` — demo/index.html, demo/style.css, demo/app.js, demo/images/pic1-5.jpg
- `original/` — burimi origjinal i paprekur
